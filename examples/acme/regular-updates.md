# Acme Analytics: regular updates

Two templates. Write the numbers from the [budget tracker](budget-tracker.csv), never from memory. Lead with what changed and what you'll do, not with charts.

---

## Weekly update

**For:** your manager, Sales leadership, Finance (cc). **When:** Monday by noon, covering the prior week. **Length:** fits on one screen; 5 minutes to read. Send as an email or a Slack post; use the [slide template](slide-template.md) only if someone asks for slides.

**Subject:** Acme Analytics marketing, week of [date]: [one-line headline, e.g. "Pipeline on pace, LinkedIn CPL up 30%"]

1. **Results vs goal (month to date)**

   | | Actual | Plan to date | Status |
   | --- | --- | --- | --- |
   | Spend | | | on pace / over / under |
   | MQLs | | | |
   | SQLs | | | |
   | SAOs | | | |
   | Pipeline | | | |

   Monthly plan: $20,000 spend, 56 MQLs, 8.3 SAOs, $250,000 pipeline.

2. **What changed and why** (3 bullets max): the biggest move, its cause, and whether it's ours or outside.
3. **What's next** (3 bullets max): actions this week, each tied to a cause above.
4. **Tests:** what's running, what finished, the decision.
5. **Asks:** decisions or help needed, with an owner and a date. Write "None" if none.

## Monthly report

**For:** leadership team, Sales, Finance, RevOps. **When:** by the 5th business day of the month. **Length:** 1-2 pages or 5-7 slides from the [slide template](slide-template.md).

1. **Headline:** one sentence: pipeline vs plan and the main reason.
2. **Funnel vs plan:** spend, MQLs, SQLs, SAOs, pipeline, closed won, each with plan, actual and variance. Conversion rates between stages vs the plan's (25% (default), 60% (default), 20% (default)).
3. **Capture vs creation:**
   - Capture: pipeline, cost per SAO, branded vs non-branded search.
   - Creation: target-account reach and engagement, self-reported source, influenced pipeline (lower confidence).
4. **What drove the result:** the top 2-3 causes, split into levers we control (budget, bids, copy, pages) and outside forces (seasonality, competitors, market).
5. **Tests:** finished tests and results, what we learned, what's next from the [experiment database](experiment-database.csv).
6. **Budget:** spend vs plan, next month's reallocation and why.
7. **Next month:** top 3 priorities, risks, asks.
